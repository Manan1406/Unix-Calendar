# [PA 2: Unix Calendar](https://cse29.site/pa2)

Due date: May 6 23:59 PDT (in UNIX time: 1746601199)

Implement a 7-day calendar that stores each day's events in a linked list.
Enable users to create, duplicate, reschedule, delete, and search for events
while avoiding time conflicts between events. Represent all points in time using
Unix time.
